__TITLE__

Ziehe ein Widget an seiner Kopfzeile. Ändere die Größe an der Ecke unten rechts. Die Daten schreibt Claude in einer Sitzung in die Datenbank dieser Seite. „Auffrischen“ bittet Claude um neue Daten.

Befehle für Claude Code

Gib einen Befehl in einer Claude-Code-Sitzung ein. Das Preset dieser Seite heißt <preset>. Ein Klick auf einen Befehl markiert ihn zum Kopieren.

/dashboard <preset>
Prüft die Seite, stellt sie neu, wenn die Vorlage neuer ist, und füllt alle Widgets.
/dashboard refresh <preset>
Holt nur neue Daten für alle Widgets. Die Seite selbst bleibt, wie sie ist.
/dashboard refresh <preset> <widget>
Holt neue Daten für ein Widget: todos, jira, sessions, status, statustable, feed oder list:<skill-id>.
/dashboard sync <preset>
Schreibt deine Markierungen aus dem Widget „Aufgaben“ nach zotero2ai. Claude zeigt zuerst die Liste und schreibt erst nach deinem Ja.
/dashboard add <preset> <widget>
Fügt ein Widget dauerhaft zum Preset hinzu und stellt es unten auf die Seite.
/dashboard help
Zeigt diese Liste im Chat.

Die Knöpfe „Auffrischen“ und „Alle auffrischen“ schicken den passenden refresh-Befehl als Kommentar an Claude.
